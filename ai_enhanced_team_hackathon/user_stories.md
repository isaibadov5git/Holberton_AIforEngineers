# User Stories - District Thermal Load & Waste-Heat Site Screener

## User Story 1
As an Energy Planner, I want to submit a site screening form with station name, exhaust temperature (°C), volumetric airflow rate (m³/s), and target output water temperature (°C) so that I can evaluate waste-heat recovery potential quickly.

## User Story 2
As an Energy Planner, I want the system to automatically validate physical bounds (such as positive airflow rates and realistic exhaust temperatures) so that invalid inputs do not corrupt feasibility calculations.

## User Story 3
As a Thermal Systems Engineer, I want the application to calculate recoverable thermal power (kW) and projected heat pump Coefficient of Performance (COP) for each submitted site so that I can verify thermodynamic viability.

## User Story 4
As a Thermal Systems Engineer, I want to receive an AI-generated engineering assessment highlighting site strengths, integration risks, and recommended heat-pump configurations so that I have actionable technical context beyond raw numbers.

## User Story 5
As a Sustainability Officer, I want to view annual recovered energy (MWh/year) and estimated CO₂e emissions avoided (metric tons/year) for every screened location so that I can prioritize high-impact decarbonization projects.

## User Story 6
As a Project Lead, I want to view all screened sites in a sortable multi-site comparison dashboard ranked by recoverable kW, COP, or annual CO₂e offset so that I can compare candidate hubs side by side.

## User Story 7
As a Project Lead, I want to filter screened sites by minimum COP threshold (e.g., COP ≥ 3.8) or site category (transit shaft vs. industrial exhaust) so that I can isolate top-performing candidates.

## User Story 8
As an Energy Planner, I want to export the screened sites table and AI feasibility scores into a downloadable CSV file so that I can share structured reports with municipal stakeholders.

## User Story 9
As a Hackathon Judge or Demo User, I want to load pre-populated sample transit hub datasets (such as 28 May, Gənclik, and 20 Yanvar stations) with one click so that I can test the comparison dashboard and AI recommendations immediately.
