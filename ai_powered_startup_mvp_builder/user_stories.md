# User Stories - AstemLab Urban Grid Analytics MVP

## User Story 1
As a Municipal Transit Engineer, I want to view live airflow velocity (m/s) and temperature (°C) readings for up to 10 subway ventilation shafts so that I can monitor underground tunnel conditions in real time.

## User Story 2
As a Municipal Transit Engineer, I want to filter telemetry cards by transit station (such as 28 May, 20 Yanvar, or Gənclik) so that I can inspect specific hubs without scrolling through unrelated data.

## User Story 3
As a District Heating Planner, I want to view the estimated recoverable thermal power (kW) and Coefficient of Performance (COP) for each shaft so that I can evaluate waste-heat integration feasibility for district heating networks.

## User Story 4
As a District Heating Planner, I want to adjust target output water temperatures (between 60°C and 90°C) in an interactive estimator so that I can see how heat pump efficiency responds to seasonal tunnel temperatures.

## User Story 5
As a Transit Maintenance Operator, I want to configure custom high-temperature and moisture alert thresholds for each ventilation shaft so that abnormal conditions are flagged immediately.

## User Story 6
As a Transit Maintenance Operator, I want to view a prioritized feed of active threshold breaches with timestamps and severity badges so that I can dispatch field teams promptly.

## User Story 7
As a Field Technician, I want to check the thermoelectric generator (TEG) harvest voltage (mV) and capacitor charge level of each sensor node so that I can confirm self-powered operation without battery failures.

## User Story 8
As an Urban Sustainability Officer, I want to view cumulative recovered thermal energy (MWh) and projected CO2 equivalent (CO2e) reductions across all monitored stations so that I can track municipal climate targets.

## User Story 9
As an Urban Sustainability Officer, I want to export filtered station telemetry and carbon savings summaries as a downloadable CSV file so that I can include verified figures in feasibility reports.

## User Story 10
As a Demo Evaluator, I want to load pre-configured sample telemetry streams with one click so that I can test dashboard analytics and alert triggers immediately without external hardware.
