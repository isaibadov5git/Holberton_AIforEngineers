# Data Model - District Thermal Load & Waste-Heat Site Screener

## Entity Relationship Overview

---

## Entity 1: `ScreeningSession`
Represents a user's active evaluation workspace and holds configuration defaults for regional grid emission factors and operating hours.

| Field Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `session_id` | `STRING (UUID)` | Primary Key, Not Null | Unique identifier for the screening session. |
| `project_title` | `STRING(120)` | Not Null | Name of the municipal or district screening batch. |
| `annual_operating_hours` | `INTEGER` | Not Null, `1` to `8760`, Default: `6500` | Assumed annual runtime hours used for MWh and CO₂e projections. |
| `grid_emission_factor` | `FLOAT` | Not Null, `> 0`, Default: `0.42` | Regional grid carbon intensity in kg CO₂e per kWh displaced. |
| `created_at` | `DATETIME (ISO-8601)` | Not Null | Timestamp when the screening session was initialized. |

---

## Entity 2: `CandidateSite`
Represents a physical transit ventilation shaft or industrial exhaust outlet submitted for waste-heat recovery screening.

| Field Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `site_id` | `STRING (UUID)` | Primary Key, Not Null | Unique identifier for the candidate site. |
| `session_id` | `STRING (UUID)` | Foreign Key (`ScreeningSession`), Not Null | Reference to the parent screening session. |
| `site_name` | `STRING(100)` | Not Null | Name of the transit hub or facility (e.g., `"28 May Transit Shaft"`). |
| `site_category` | `ENUM` | Not Null | Classification (`"TRANSIT_SHAFT"`, `"INDUSTRIAL_EXHAUST"`, `"DATA_CENTER"`). |
| `exhaust_temp_c` | `FLOAT` | Not Null, `5.0` to `120.0` | Measured waste-heat exhaust temperature in degrees Celsius. |
| `airflow_rate_m3s` | `FLOAT` | Not Null, `> 0.0` | Volumetric exhaust airflow rate in cubic meters per second. |
| `target_supply_temp_c` | `FLOAT` | Not Null, `45.0` to `95.0` | Desired district heating supply water temperature in degrees Celsius. |

---

## Entity 3: `ThermodynamicEvaluation`
Stores deterministic engineering outputs computed from a `CandidateSite`'s physical parameters.

| Field Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `eval_id` | `STRING (UUID)` | Primary Key, Not Null | Unique identifier for the thermodynamic calculation record. |
| `site_id` | `STRING (UUID)` | Foreign Key (`CandidateSite`), Unique, Not Null | One-to-one reference to the evaluated candidate site. |
| `recoverable_power_kw` | `FLOAT` | Not Null, `>= 0.0` | Estimated thermal recovery capacity in kilowatts ($Q = \rho \cdot \dot{V} \cdot c_p \cdot \Delta T$). |
| `projected_cop` | `FLOAT` | Not Null, `>= 1.0` | Estimated heat pump Coefficient of Performance based on Carnot efficiency factor. |
| `annual_energy_mwh` | `FLOAT` | Not Null, `>= 0.0` | Projected annual thermal energy delivered in megawatt-hours. |
| `annual_co2_offset_tons` | `FLOAT` | Not Null, `>= 0.0` | Estimated annual greenhouse gas reduction in metric tons of CO₂e. |

---

## Entity 4: `AIFeasibilityReport`
Stores structured qualitative insights and viability scoring generated by the LLM prompt pipeline for each site.

| Field Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `report_id` | `STRING (UUID)` | Primary Key, Not Null | Unique identifier for the AI feasibility assessment. |
| `site_id` | `STRING (UUID)` | Foreign Key (`CandidateSite`), Unique, Not Null | One-to-one reference to the evaluated candidate site. |
| `viability_tier` | `ENUM` | Not Null | Assigned screening grade (`"HIGH"`, `"MODERATE"`, `"LOW"`). |
| `summary` | `TEXT` | Not Null | Plain-English engineering summary of site waste-heat potential. |
| `recommended_equipment` | `STRING(200)` | Not Null | Suggested heat-exchanger and heat-pump configuration. |
| `key_risks` | `TEXT` | Not Null | Primary technical or integration constraints identified by AI. |
